# Divine Training - Quick Start (5 Minutes)

## Step 1: Get Node.js
Download from https://nodejs.org (version 16 or higher)

## Step 2: Run Locally
```bash
cd divine-training-app
npm install
npm start
```

Open: `http://localhost:3000`

## Step 3: Create Accounts

**Account 1 - Sekou (Trainer)**
- Name: Sekou Kaba
- Email: sekou@example.com
- Password: (anything)
- Role: Trainer

**Account 2 - You (Client)**
- Name: Chris
- Email: chris@example.com
- Password: (anything)
- Role: Client

## Step 4: Sekou Sets Up Workouts

Log in as Sekou → "Manage Workouts"

Create "Day 1 - Upper Body"
Add exercises from your PDF:
- Lat Pulldown | 3 x 8-12
- Dumbbell Bench Press | 3 x 8-12
- Seated Cable Row | 3 x 10-12
- Dumbbell Shoulder Press | 3 x 8-12
- Cable / Lateral Raises | 3 x 12-15
- Rope Triceps Pushdown | 4 x 10-15
- Dumbbell / Cable Curls | 3 x 10-15

Create "Day 2 - Lower Body"
Add exercises:
- Goblet Squat or Leg Press | 3 x 8-12
- Romanian Deadlift | 3 x 8-12
- Walking Lunges or Split Squats | 2 x 8-10
- Leg Curl | 2 x 10-15
- Calf Raises | 2 x 12-15
- Core: Dead Bug or Pallof Press | 2-3 sets

## Step 5: You Log a Workout

Log in as Chris → "Log Workout"

Pick Day 1 or Day 2 → Enter weight and reps → Save

Done!
